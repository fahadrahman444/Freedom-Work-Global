1. Visual hierarchy

Guide the user's attention to the most important information first.

    Use size, weight, color, and spacing to establish importance.

    Make headings more prominent than body text.

    Make the primary action easy to identify.

Example: A landing page headline should stand out more than its footer text.

2. Spacing and alignment

Consistent spacing makes interfaces feel clean and professional.

    Understand margin, padding, and gaps.

    Align elements to a consistent grid.

    Use a spacing scale, such as 4, 8, 16, 24, and 32 pixels.

Example: Cards in the same row should have consistent internal padding and gaps.

3. Typography

Typography controls readability, tone, and visual hierarchy.

    Learn font families, weights, sizes, and line height.

    Use a consistent type scale.

    Keep paragraphs readable and headings distinct.

Example: Use a strong heading, comfortable body text, and readable line spacing instead of many unrelated font sizes.

4. Color theory

Use colors to create consistency and communicate meaning.

    Primary, secondary, and accent colors.

    Neutral colors for backgrounds and text.

    Contrast, color harmony, and accessible color combinations.

    Semantic colors for success, warning, and error.

Example: Use the same primary color for key actions throughout an application, and don't rely on color alone to communicate errors.

5. Layout and composition

Organize content so it is balanced and easy to scan.

    Grids, columns, and containers.

    Proximity and grouping.

    Balance, whitespace, and consistency.

    Responsive layouts for different screens.

Example: A three-column product grid on desktop may become two columns on a tablet and one column on a phone.

6. Components and interaction states

Design reusable elements that behave predictably.

    Buttons, inputs, cards, modals, and navigation.

    Default, hover, focus, active, disabled, and loading states.

    Clear feedback after user actions.

Example: When a user submits a form, show a success message or an understandable error.

7. User flows and navigation

Help users reach their goals with minimal confusion.

    Information architecture.

    Navigation patterns and page structure.

    User journeys and task flows.

    Clear labels and predictable interactions.

Example: A checkout process should make it clear where the user is, what comes next, and how to correct a mistake.

8. Accessibility

Make interfaces usable by people with different abilities and needs.

    Sufficient text contrast.

    Keyboard navigation and visible focus.

    Proper labels for form controls.

    Semantic HTML and screen-reader support.

    Touch targets that are easy to activate.

Example: A button should be usable with a keyboard and have an accessible name.

9. Wireframing and prototyping

Plan and test an interface before writing all the code.

    Low-fidelity wireframes.

    High-fidelity mockups.

    Clickable prototypes.

    Design handoff and specifications.

Example: Build a Figma prototype of a signup flow before implementing it in React.

10. Usability testing and iteration

Check whether a design works for real users.

    Observe users completing common tasks.

    Identify confusing steps and interface problems.

    Gather feedback and improve the design.

    Check empty, error, loading, and success scenarios.

Example: If users cannot find the search feature, improve its placement or visual prominence.
